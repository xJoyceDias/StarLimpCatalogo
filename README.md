# Star Limp — Catálogo Premium

Catálogo estático da Star Limp, preparado para edição no VS Code e deploy no Cloudflare Pages.

## Estrutura

- `index.html` — catálogo completo
- `assets/` — reservado para imagens, ícones e outros assets futuros

## Rodar localmente

Abra a pasta no VS Code e use a extensão Live Server, ou abra `index.html` diretamente no navegador.

## Deploy

O projeto pode ser conectado a um repositório GitHub e publicado pelo Cloudflare Pages.

## WhatsApp

No `index.html`, procure por:

`const WHATSAPP_NUMBER="5562999999999";`

e substitua pelo número real da Star Limp.
